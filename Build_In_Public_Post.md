I just shipped my engineering portfolio: betmutema.github.io

One real decision: I built it as plain HTML/CSS on GitHub Pages instead of a no-code builder or a React app. I considered both, a no-code tool would hit free-tier limits for content I don't need to gate, and React would mean maintaining a build pipeline for a site that's fundamentally four static pages. Plain HTML meant I could ship in an afternoon and maintain it with zero moving parts.

One real limitation: my hero background image took four separate generation attempts to get right, and even then, I can't guarantee the exact color match to my identity kit's hex codes without manually checking with a color picker. AI image generation is fast, but "close enough by eye" isn't the same as verified, and I said so honestly in my own build log rather than assuming it matched.

Everything on the site, the case studies, the diagrams, the identity kit, is real and checkable. Repo's public if you want to see how it's built: github.com/betmutema/betmutema.github.io
